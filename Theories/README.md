# 单模态 MIL 方法路线

本路线收录**单模态 MIL 方法**：通用 MIL 是基础，WSI 是目前收录最多的应用，但乳腺影像、眼底、超声等单模态方法同样属于本路线。阅读时先问主要改动发生在哪里：**包如何构造 → 实例如何表征和选择 → 实例关系如何聚合 → 预测如何变得可靠、可解释且高效**。传统方法和注意力聚合是理解后续工作的基础，因此固定为第 1、2 类。文本、预训练大模型或其他模态实质参与学习的方法另见[Multimodal](../Multimodal/README.md)。

## 一张路线图

MIL 的基本对象是包 $B=\{x_1,\ldots,x_n\}$，训练标签通常只有 $Y_B$。早期方法把包转成特征或相似度；深度 MIL 则学习实例编码 $h_i=f(x_i)$ 与置换不变的包聚合 $z=g(\{h_i\})$。**1–2 类**给出基本范式和注意力基线；**3–5 类**改善空间关系、长程依赖和实例表征；**6–8 类**处理弱标签下的实例选择、包构造与知识利用；**9–13 类**分别针对伪相关、解释与人工反馈、不确定性、计算成本及任务特有目标。分类是按主要贡献导航，不暗示方法只能包含一种模块。

一个实用的阅读顺序是：先看 [传统 MIL](1Traditional.md) 与 [注意力 MIL](2Attention.md)，再按研究问题进入相应分支；如果研究的是某一疾病或采集模态的**数据和评估**，转到 [Applications](../Applications/README.md)。

每篇论文只在**主要贡献**所属的页面保留一行；确实涉及两个核心方向时，可以在文字中说明次要方向，不在多个表格重复收录。分类依据是论文解决的主要问题和核心机制，而非模型里出现过的每个模块。

## 如何处理交叉方法

- **看主要思路**：RGMIL 以图建模为主，强化学习用于搜索图结构，主类为 3；PCR-MIL 以构造低噪声伪包为主，强化学习用于优化特征提取，主类为 7。
- **区分骨架和训练信号**：ItS2CLR 用伪标签支持监督对比学习，其主要目标是学习更好的实例表征，主类为 5。
- **特殊问题值得独立呈现**：类别 token、强化学习、自编码器通常仍是组件；但解释忠实性与专家可干预的学习过程属于独立问题，不能简单并入原型学习。热图可视化不等于医生参与。
- **先辨认论文，再辨认缩写**：本库同时收录两篇简称 PAMIL 的不同论文，表格中以“动态策略”和“伪标签注意力”加以区分。`CAMIL` 与 `CaMIL` 也不是同一方法。
- **辨认是否真是 MIL 问题**：不因标题含 *multi-instance* 就自动并入弱包标签学习。例如本地参考中的 PMITra 主要解决跨域行人轨迹预测，使用多实例图卷积迁移行为模式，但没有以包级弱标签学习作为核心问题，暂不列为 MIL 方法行。
- **区分版本与相关资源**：同一方法的会议版和期刊版只列一次，如 PacMIL 用 2026 年期刊版本；病理基座模型和可复用数据资源另列于 [Multimodal](../Multimodal/README.md) 或 [Applications](../Applications/README.md)，不混算直接 MIL 方法。

表格沿用原有的“方法名、团队、期刊/会议、全称、思想、领域”六列；“思想”尽量用一句话写清主要机制。每页按表中**正式期刊/会议年份降序**排列，同年没有统一且可核验的发表日期时不推断月日先后；分类编号是学习路线，不是发表先后。✳表示适合入门，★表示相对简单。
