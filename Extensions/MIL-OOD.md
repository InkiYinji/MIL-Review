# MIL 分布外检测（MIL-OOD）

目标是在测试时识别**不属于训练分布的包**，并避免把未知组织或未知类别误作已知类别的高置信预测。应分别说明包级/实例级 OOD 定义，以及未知类别、染色/设备变化、跨中心偏移等评估设置。

目前尚无经过本库核实、以 **MIL 包级 OOD 检测为主要贡献** 的独立方法行，因此这里暂不填充未经核对的论文。作为相邻工作，[AttriMIL](../Theories/2Attention.md) 在以注意力机制为主要贡献的同时报告了 OOD 实验；[因果与稳健学习](../Theories/9CausalRobustness.md)则关注分布变化下的泛化。这两类结果不能直接等同于专门的 OOD 检测方法。

后续收录时需核对论文是否明确使用包级弱监督训练，并报告包级 OOD 指标、未知样本来源及与普通域泛化的区别。
